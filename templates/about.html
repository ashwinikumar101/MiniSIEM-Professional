🛡️ About MiniSIEM

MiniSIEM Professional is a lightweight Security Information and Event Management (SIEM) platform developed using Python, Flask, and PostgreSQL (Neon).

It collects, monitors, analyzes, and visualizes security events from Windows and Linux systems through a centralized web dashboard. The platform provides real-time monitoring, security alerts, analytics, role-based access control (RBAC), and report generation to help administrators detect and investigate security incidents efficiently.
